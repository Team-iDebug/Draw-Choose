# Draw-Choose

Draw-Choose is a fun and engaging multiplayer drawing and guessing game inspired by Skribbl.io. Built in Java, it features an interactive drawing interface, real-time multiplayer functionality, and a variety of random prompts to keep every round exciting. Whether you're looking to test your artistic skills or enjoy a game of rapid-fire guessing with friends, Draw-Choose offers endless fun!

## Features

- **Real-Time Multiplayer:** Enjoy live gameplay where players draw and guess in real-time.
- **Interactive Drawing Interface:** A user-friendly GUI that makes drawing fun and intuitive.
- **Random Prompts:** Each round provides new drawing prompts to keep the game fresh and unpredictable.
- **Time-Based Rounds:** Keep the pace exciting with a built-in time limit for each drawing session.
- **Networking Capabilities:** Demonstrates robust Java networking and GUI development.

## Getting Started

Follow these instructions to set up and run Draw-Choose on your local machine.

### Prerequisites

- **Java JDK:** Ensure that you have Java Development Kit (JDK) installed (version 8 or higher is recommended).
- **Git:** To clone the repository.
- A modern IDE (e.g., IntelliJ IDEA, Eclipse) for code editing and debugging.

### Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/Team-iDebug/Draw-Choose.git
   ```
2. **Navigate to the Project Directory:**
   ```bash
   cd Draw-Choose
   ```
3. **Open the Project:**
   - Open the project in your preferred Java IDE.

### Running the Game

1. **Compile the Source Code:**
   - Use your IDE’s build tools to compile the Java source code.
2. **Start the Server:**
   - Run the main server class (e.g., `Server.java`) to start hosting the game.
3. **Launch the Client:**
   - Run the client class (e.g., `Client.java`) on the same machine or different machines to join the game.
4. **Enjoy the Game:**
   - Follow on-screen instructions to start drawing and guessing!

## How to Play

- **Drawing:** Players take turns drawing a given object or concept based on a randomly selected prompt.
- **Guessing:** Other players try to guess what is being drawn within a set time limit.
- **Scoring:** Points are awarded based on how quickly and accurately guesses are made.
- **Rounds:** The game consists of multiple rounds, ensuring every player gets a chance to be both the artist and the guesser.

## Technologies

- **Java:** Core language used for the game logic.
- **Java Swing:** For building the interactive GUI.
- **Java Networking:** For handling real-time multiplayer functionalities.
